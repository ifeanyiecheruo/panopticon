# Panopticon

Panopticon repurposes old Android phones as standalone, cloud-free security cameras.
## Getting started

```bash
make install-tools   # one-time install of development tools
make build           # build both phone app and desktop controller
make test            # run test suites
make help            # full task list
```

Build/run/test detail, prerequisites, and the dev-environment notes are in
[`CONTRIBUTING.md`](CONTRIBUTING.md).
